    Acceptance profiles¶

    How far speculative decoding advances a request per verification step, by model, speculative method, K and thinking mode. Generated at build time from acceptance/, at revision [`883a2709c250`](https://github.com/inference-sim/blis-substrate/tree/883a2709c250e4724ce11d1d6ba2cc12662b01e7); nothing below is typed in by hand.

    An acceptance-profile set is the acceptance counterpart of a coefficient set. Its format, and how a run resolves one value from it, are on the contracts' acceptance reference (https://github.com/inference-sim/blis-schemas/issues/65). Each profile holds the mean acceptance length (AL): the tokens a request gains per verification step, counting the target's bonus token, so it lies in [1, K + 1]. No per-position rates are stored. A consumer that needs them derives vLLM v0.31.0's minimum-variance schedule, which is how the InferenceX runs that force a published AL realise it.

    Caveats¶

    The set's own caveats, as committed:

    • Coding only. Every profile is SPEED-Bench's coding category, the only one InferenceX publishes; no other category has a value. A consumer must refuse other traffic, or fall back to coding with the substitution recorded; it must not substitute silently.
    • Measured on b300: deepseek-v4-pro, deepseek-v4-pro-0813, glm-5.2-fp8, glm-5.3, glm-5.3-flash, glm-5.3-nvfp4, kimi-k3, kimi-k3.1, minimax-m3, qwen3.5-397b-a17b-nvfp4, qwen3.8-flash-next-fp8. Acceptance depends mostly on the model, drafter and workload rather than the chip; a resolution on another part records the reuse.
    • Measured on b200: deepseek-v4.1-flash, minimax-m3.1-flash, muse-spark-open-816b-a42b-nvfp4. Acceptance depends mostly on the model, drafter and workload rather than the chip; a resolution on another part records the reuse.
    • Natural acceptance. Every curve was collected with real verification (InferenceX README, How a golden AL curve is collected), so each value is a natural acceptance length; InferenceX's AgentX runs then force it with the engine's synthetic rejection sampler. The set's shapes, fitted to every vendored curve, spread a natural value that states no per-position rates.
    • deepseek-v4.1-flash with dspark at K 6-8 was rejected by the image vllm/vllm-openai:deepseekv41-flash-0909 (https://github.com/SemiAnalysisAI/InferenceX/actions/runs/34494319147), so those K have no value.
    • glm-5.3 mtp is transferred from glm-5.3-nvfp4__mtp__native__default-default.yaml, measured on glm-5.3-nvfp4, not on glm-5.3.
