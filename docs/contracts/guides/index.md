# Guides

<p class="lede">Each guide does one task from start to finish, with commands and documents
you can copy.</p>

[Validate the catalog and the registry](checkouts.md)
:   Run the checks CI runs on `catalog/` and `registry/`, and read their output.

[Write a scenario and a deployment](authoring.md)
:   Describe a run, from one colocated node to a disaggregated deployment across several,
    and fix the messages you are likely to see.

[Validate documents from Go](go.md)
:   Load documents, validate them together, read the report, and resolve names against a
    catalog directory.

[Measure how far the router policy moves a figure](router-sensitivity.md)
:   Run the sweep behind the router table's bounds, read its ratios, and see what they leave out.
